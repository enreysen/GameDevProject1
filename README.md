

# Game Overview

Crab Run is a side-scrolling platformer where players control an explorer navigating both land and sea. After an ocean adventure, a massive, murderous crab follows the explorer. Players must maintain their distance from the giant crab in both on-land and underwater levels by dodging obstacles like barrels, seagulls, and aquatic animals–all while also continuously damaging the boss to defeat it!

# Main Controls

Move forward: D key/the right arrow key

Jump (on land only): Spacebar

Swim upwards (underwater only): Press spacebar for quick boost, hold down spacebar for continous upward movement

Dash: F key

Shoot: V key
